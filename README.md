# Workshop de Letramento Estatístico

Repositório de materiais do Workshop de Letramento Estatístico, promovido pelo
Laboratório de Estatística Aplicada (LEA) do Departamento de Estatística/CCET/UFRN.

## Sobre o workshop

O Workshop de Letramento Estatístico é uma iniciativa voltada à introdução de
conceitos fundamentais de Estatística e ao desenvolvimento de habilidades para
coleta, organização, tratamento, visualização e exploração de dados.

O workshop tem caráter prático, buscando aproximar os participantes de conceitos
e ferramentas estatísticas que podem ser aplicados em diferentes contextos de
ensino, pesquisa e extensão.

## Pré-requisitos

Para acompanhar as atividades práticas, recomenda-se instalar o
[R e o RStudio](https://posit.co/download/rstudio-desktop/). Quem não puder
instalar pode usar a versão em nuvem: [Posit Cloud](https://posit.cloud/).

Pacotes utilizados no Dia 3:

```r
install.packages(c("tidyverse", "palmerpenguins", "ggthemes"))
```
